# Release 0.51.0: fluid desktop workspace and the Settings center

- **Completed:** 2026-10-05
- **Version:** 0.51.0

## Summary

Combined two independently prepared features into one release with one version and one tag:

- PR #12 — the fluid desktop workspace that replaces the centered `container-xl` (issue #6), prepared
  as 0.50.1;
- PR #13 — the section-based Settings center (issue #4), prepared as 0.51.0.

The branches were merged into `master` with merge commits in that order, so each PR keeps its own
commit. Conflicts were resolved as follows:

- **Versions:** `package.json` and `package-lock.json` are 0.51.0, and `shared/release-history.json`
  has a single 0.51.0 entry with the fluid workspace bullet followed by the Settings center bullets.
  The 0.50.1 entry was never published and was dropped. The change record of PR #12 now names 0.51.0.
- `AGENTS.md`, `client/src/style.css`, `docs/HOW-TO.md`, and `docs/features/application-ui.md` merged
  without conflicts; their combined text describes both changes. The Settings sections keep their
  `.form-card` width inside the fluid workspace, which `test/e2e/fluid-workspace.spec.js` checks on
  `/settings`.
- `docs/ROADMAP.md` no longer lists the fluid workspace (removed by PR #12) and is dated 2026-10-05.
