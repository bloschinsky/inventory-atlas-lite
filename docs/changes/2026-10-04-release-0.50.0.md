# Release 0.50.0: photo order, Condition grading, and New/Used badges

- **Completed:** 2026-10-04
- **Version:** 0.50.0

## Summary

Combined three independently prepared features into one release with one version and one tag:

- PR #9 — item photo ordering and cover photo selection (issue #3), prepared as 0.50.0;
- PR #10 — the New flag shown as New/Used status badges (issue #7), prepared as 0.49.1;
- PR #11 — structured Condition grading, Condition Notes, and the help dialog (issue #8), prepared as
  0.51.0.

The branches were merged into `master` with merge commits in that order, so each PR keeps its own
commits. Conflicts were resolved as follows:

- **Schema version 7** now holds both migrations: `item_photos.sort_order`, and the rename of the
  free-text `condition` to `condition_notes` with the new `condition_grade`. Neither had been released,
  and both are idempotent column checks inside `applySchema()`, so a database created on either feature
  branch is still completed on the next start. `SCHEMA_VERSION` stays `7`.
- **Container contents** select `condition_grade` and take the thumbnail from the shared
  `coverPhotoIdSql()`, so the cover rule of the photo order applies there too.
- **Items table and cards** use both `ItemNewStatusBadge` and `ConditionGradeBadge`; the `isNew` column
  text is New/Used and the Condition text is the localized grade.
- **Versions:** `package.json` and `package-lock.json` are 0.50.0, and `shared/release-history.json`
  has a single 0.50.0 entry with the bullets of all three features. The 0.49.1 and 0.51.0 entries were
  never published and were dropped. The change records of PR #10 and PR #11 now name 0.50.0.
- **Docs:** `docs/HOW-TO.md`, `docs/features/README.md`, `database-backup-and-restore.md`, and
  `item-new-flag.md` describe the combined behavior (the New/Used badge next to the Condition grade,
  and both version 7 changes).
- The unpublished local tags `v0.49.1`, `v0.50.0`, and `v0.51.0`, which pointed at the feature branch
  commits, were removed; `v0.50.0` now marks the release commit.
